# AKO Stock Take (ERPNext app)

Frappe app for barcode stock taking. Pairs with the mobile client in `/mobile`.

**Author:** Justin Msengi · Koda Technologies  
**Email:** justinemsengi@gmail.com  

## Install

See the root `INSTALL.md` or run `install-erpnext.sh` from the repo root.

## Main pieces

- DocTypes: Stock Take Session, Stock Take Item, Stock Take Settings, Stock Take Variance Reason  
- Workspace: Stock Take  
- Reports: Summary, Variance, Exception  
- API: `ako_stock_take.api.stock_take.*`
